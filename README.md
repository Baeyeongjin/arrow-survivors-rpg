# Arrow Survivors RPG (Godot 4)

자동 기본공격의 접근성 위에 무기 스킬·회피·궁극기·장비 성장을 결합한 4방향 로그라이크 RPG입니다.
캐릭터와 장비를 준비하고 던전·난이도·가호를 선택한 뒤, 정예와 보스를 공략해 전리품을 마을로 가져옵니다.

## 조작

- **이동**: 방향키 또는 `WASD`
- **기본공격**: 자동
- **무기 스킬**: `E` (장착 무기·마우스 방향)
- **회피/대시**: `Space` (이동 방향, 짧은 무적)
- **캐릭터 궁극기**: `Q` (게이지 충전 후)
- **인벤토리**: `I`
- **일시정지**: `Esc`
- 레벨업 시 카드 3장 중 1장 클릭 선택

`E`는 검(무적 반격), 도끼(광역 경직), 지팡이(속성 폭발), 단검 계열(고치명 난사), 창(돌진 관통)의 5개 조작 문법으로 나뉩니다. 장비가 없으면 캐릭터 고유 시작 무기의 이름·투사체·부가효과를 사용합니다.

## 게임 흐름

1. 캐릭터·영구 장비를 고르고 던전, 난이도, 가호를 확정합니다.
2. 자동공격과 능동 스킬로 적을 처치하고 레벨업 카드와 런 장비를 획득합니다.
3. 예고된 일반·정예 공격을 회피하며 5분 뒤 등장하는 던전 보스를 공략합니다.
4. 클리어한 장비와 골드를 대장간 성장에 사용합니다.

## 파워업
연사 강화 · 멀티샷 · 날카로운 촉(공격력) · 관통 · 신속(이동속도) · 플라잉 소드(공전 검) · 체력 강화

## 실행 방법
1. [Godot Engine 4.2+](https://godotengine.org/download) 다운로드 (무료, 설치 불필요한 단일 실행파일)
2. Godot 실행 → **Import** → 이 폴더의 `project.godot` 선택
3. 우측 상단 ▶ (Play) 버튼 또는 `F5`

## 파일 구조
| 파일 | 역할 |
|------|------|
| `project.godot` | 프로젝트 설정 (해상도 480x800 세로) |
| `Main.tscn` / `Main.gd` | 게임 매니저 (스폰·충돌·레벨업·UI·상태) |
| `Player.gd` | 플레이어 (이동·자동발사·스탯) |
| `Arrow.gd` | 아군 화살 (관통·멀티샷) |
| `Enemy.gd` | 잡몹 |
| `EnemyArrow.gd` | 보스 탄막 |
| `Boss.gd` | 보스 (왕복 이동·탄막·체력바) |
| `Pet.gd` | 플라잉 소드 (공전·자동 조준) |

> 모든 그래픽은 코드(`_draw`)로 그려서 별도 이미지 에셋 없이 바로 실행됩니다.

## 📦 Windows 실행파일(.exe) 내보내기 가이드

1. Godot 에디터 상단 메뉴 → **프로젝트 > 내보내기(Export)**
2. **프리셋 추가 → Windows Desktop** 선택
3. 처음이면 "내보내기 템플릿 다운로드" 안내가 뜸 → **다운로드 및 설치** 클릭 (1회만, ~700MB)
4. 프리셋 설정:
   - Binary Format: **Embed PCK 체크** (단일 exe 파일로 만들기)
   - 아이콘 등은 선택사항
5. **프로젝트 내보내기** → 저장 위치 선택 → `ArrowSurvivors.exe` 완성
6. 그 exe 하나만 전달하면 누구나 실행 가능 (설치 불필요)

> 웹 버전을 원하면 프리셋에서 **Web**을 추가해 HTML5로 내보내고 itch.io에 무료 업로드 가능
