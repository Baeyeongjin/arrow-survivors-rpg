# Arrow Survivors RPG (Godot 4)

자동 기본공격의 접근성 위에 무기 스킬·회피·궁극기·장비 성장을 결합한 4방향 로그라이크 RPG입니다.
캐릭터와 장비를 준비하고 던전·난이도·가호를 선택한 뒤, 정예와 보스를 공략해 전리품을 마을로 가져옵니다.

## 조작

- **이동**: 방향키 또는 `WASD`
- **기본공격**: 자동
- **무기 스킬**: `E` (장착 무기·마우스 방향)
- **회피/대시**: `Space` (이동 방향, 짧은 무적)
- **캐릭터 궁극기**: `Q` (게이지 충전 후)
- **인벤토리**: `I`
- **일시정지**: `Esc`
- 레벨업 시 카드 3장 중 1장 클릭 선택

`E`는 검(무적 반격), 도끼(광역 경직), 지팡이(속성 폭발), 단검 계열(고치명 난사), 창(돌진 관통)의 5개 조작 문법으로 나뉩니다. 장비가 없으면 캐릭터 고유 시작 무기의 이름·투사체·부가효과를 사용합니다.

## 게임 흐름

1. 캐릭터·영구 장비를 고르고 던전, 난이도, 가호를 확정합니다.
2. 자동공격과 능동 스킬로 적을 처치하고 레벨업 카드와 런 장비를 획득합니다.
3. 5분 층의 보스를 공략한 뒤 캠프·상인·위험 이벤트 중 다음 경로를 선택합니다.
4. 세 번째 층의 최종 보스를 쓰러뜨리고 발견 장비 중 2개를 골라 추출합니다.
5. 미선택 장비는 자동 분해하고, 보스 파편과 골드를 대장간 성장에 사용합니다.
6. 종료 보고서에서 층별 기록·피해 비중·선택 경로·추출 결과를 확인합니다.

### 3층 원정과 추출

각 원정은 기존 수제 던전 레이아웃 3개를 연결합니다. 층을 넘겨도 무기 숙련·패시브·능력치·장비는 유지되며 적 압박은 상승합니다. 캠프는 회복과 능력치 포인트, 상인은 골드로 고급 장비, 저주받은 제단은 체력을 대가로 에픽 장비를 제공합니다. 클리어 시 발견 장비 2개를 직접 추출하고 사망 시에는 최고 가치 장비 1개만 보험 처리됩니다. 지역별 보스 파편 5개는 대장간에서 에픽 장비 하나로 제작할 수 있습니다.

### 로컬 원정 보고서

클리어와 사망 시 층별 시간·처치·피해/피격, 무기와 능동 스킬의 실제 피해 비중, 받은 피해 원인, 선택 경로와 추출 장비를 종료 화면에서 보여줍니다. 최근 100회 기록은 `user://run_telemetry.json`에 로컬로만 저장되며 외부로 전송되지 않습니다. 치트와 자동 화면 검수 런은 통계에서 제외됩니다.

### 지옥 던전

`잿불 추적자`가 지키는 용암 균열 3개를 찾아 봉인하고 2분 30초의 `용암 집행자`를 쓰러뜨리면 5분에 최종보스 `화염 군주`가 등장합니다. 보스의 원형 강타·돌진·방사 탄막을 회피하고, 체력 70%와 35%에 생성되는 화염 갑옷을 파괴하면 5초 집중 공격 시간이 열립니다. 냉기 피해는 균열과 화염 갑옷을 빠르게 파괴하며, 중간·최종보스는 다음 지옥 원정의 규칙을 유리하게 바꾸는 전용 장비를 드롭합니다.

## 실행 방법
1. [Godot Engine 4.2+](https://godotengine.org/download) 다운로드 (무료, 설치 불필요한 단일 실행파일)
2. Godot 실행 → **Import** → 이 폴더의 `project.godot` 선택
3. 우측 상단 ▶ (Play) 버튼 또는 `F5`

## 파일 구조
| 파일 | 역할 |
|------|------|
| `project.godot` | 프로젝트 설정 (기준 해상도 1280×720) |
| `Main.tscn` / `Main.gd` | 게임 매니저 (스폰·충돌·레벨업·UI·상태) |
| `RunTelemetry.gd` | 최근 원정 기록 저장·피해 순위·누적 통계 |
| `Player.gd` | 플레이어 (이동·자동발사·스탯) |
| `Arrow.gd` | 아군 화살 (관통·멀티샷) |
| `Enemy.gd` | 잡몹 |
| `EnemyArrow.gd` | 보스 탄막 |
| `Boss.gd` | 보스 (공격 전조·돌진·탄막·갑옷 페이즈) |
| `Pet.gd` | 플라잉 소드 (공전·자동 조준) |

> 모든 그래픽은 코드(`_draw`)로 그려서 별도 이미지 에셋 없이 바로 실행됩니다.

## 📦 Windows 실행파일(.exe) 내보내기 가이드

1. Godot 에디터 상단 메뉴 → **프로젝트 > 내보내기(Export)**
2. **프리셋 추가 → Windows Desktop** 선택
3. 처음이면 "내보내기 템플릿 다운로드" 안내가 뜸 → **다운로드 및 설치** 클릭 (1회만, ~700MB)
4. 프리셋 설정:
   - Binary Format: **Embed PCK 체크** (단일 exe 파일로 만들기)
   - 아이콘 등은 선택사항
5. **프로젝트 내보내기** → 저장 위치 선택 → `ArrowSurvivors.exe` 완성
6. 그 exe 하나만 전달하면 누구나 실행 가능 (설치 불필요)

> 웹 버전을 원하면 프리셋에서 **Web**을 추가해 HTML5로 내보내고 itch.io에 무료 업로드 가능
